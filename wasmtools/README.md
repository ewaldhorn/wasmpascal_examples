# WasmTools (PC Tools Tribute)

A nostalgic tribute to classic DOS utility suites like PC Tools and Turbo Vision, built in console Pascal and compiled with [WasmPascal](https://wasmpascal.com/).

Features:
- Stacked pulldown menus with keyboard hotkey access (F, D, V, T, S, C, O, M, H, Q).
- Dialog boxes with ASCII drop shadows and CP437 box-drawing borders.
- Simulated directory tree browser and system status monitors.
- Arrow key navigation, Enter selection, and Esc dismissal on an 80x25 virtual terminal.
