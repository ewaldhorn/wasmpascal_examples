# Enumerations and Subranges

Demonstrates strongly typed enumerations and named subranges in [WasmPascal](https://wasmpascal.com/).

Covers:
- Declaring enum types (`Color = (Red, Green, Blue)`) and subranges (`Index = 1..10`, `Neg = -3..3`).
- Using enums and subranges as array indices and loop bounds.
- Ordinal conversions and `case` statement dispatch.
- Set membership and ordinal operations compiled directly to WebAssembly types.
