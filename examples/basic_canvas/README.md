# Basic Canvas

Demonstrates drawing 2D graphics directly onto an HTML Canvas using [WasmPascal](https://wasmpascal.com/).

This example shows how Pascal procedures interact with the browser's graphics layer to draw geometric primitives like filled circles, lines, and animated scanlines without requiring JavaScript glue code. It highlights [WasmPascal](https://wasmpascal.com/)'s HTML Canvas integration and language extensions for web graphics.
