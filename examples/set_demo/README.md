# Set Operations

Explores Pascal's native `set of` bitmask types in [WasmPascal](https://wasmpascal.com/).

Covers:
- Set constructors (`[1, 3..5]`, `[]`).
- Set operations: union (`+`), difference (`-`), and intersection (`*`).
- Membership testing with `in`.
- Subset and equality comparisons (`<=`, `>=`, `=`, `<>`).
