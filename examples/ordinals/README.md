# Ordinal Built-ins

Demonstrates Pascal's fundamental ordinal and character built-in functions in [WasmPascal](https://wasmpascal.com/).

Exercises:
- `Ord`: Returns the ordinal integer value of a character or enum.
- `Chr`: Converts an integer ASCII code to a character.
- `Pred` and `Succ`: Predecessor and successor ordinal stepping.
- `Odd`: Boolean parity check.
- `Halt`: Program termination.
