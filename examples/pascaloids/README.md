# Pascaloids (Asteroids)

A full Asteroids-style arcade space shooter game ported to Pascal and compiled with [WasmPascal](https://wasmpascal.com/).

Features:
- Inertial spaceship physics: rotation, thrust acceleration, and screen wraparound.
- Multi-tier asteroid fracturing on projectile impact.
- Batched HTML5 Canvas2D rendering for vectors and particles.
- Synthesized audio effects and document keyboard event integration.
