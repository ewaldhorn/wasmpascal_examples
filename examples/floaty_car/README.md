# Floaty Car

A top-down arcade racing game compiled to WebAssembly using [WasmPascal](https://wasmpascal.com/).

Features:
- Continuously scrolling procedural road grid (800x600 canvas).
- Keyboard steering (A/D or Arrows) and touch/pointer steering.
- Boost speed mechanics (W/Up Arrow).
- Synthesized Web Audio engine sounds and crash effects with mute toggle.
- Zero external dependencies and zero per-frame allocations.
