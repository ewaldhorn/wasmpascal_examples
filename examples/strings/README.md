# String Operations

Demonstrates standard Pascal string manipulation functions in [WasmPascal](https://wasmpascal.com/).

Covers:
- String concatenation with `+` and `Concat`.
- Querying length with `Length`.
- Substring extraction with `Copy`.
- Substring searching with `Pos`.
- Number-to-string and string-to-number conversions using `Str` and `Val`.
- Fixed-length buffer declarations (`String[n]`).
