# Pong

A complete, real-time Pong game built with [WasmPascal](https://wasmpascal.com/).

Features:
- Player-controlled left paddle (W/S or Up/Down arrows).
- Tracking AI controlling the right paddle.
- Dynamic ball deflection angles based on paddle hit position.
- Real-time Web Audio oscillator sound effects for wall and paddle bounces.
- 60 fps batched Canvas2D graphics pipeline.
