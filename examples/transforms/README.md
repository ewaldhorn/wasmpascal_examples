# Canvas Transforms

Showcases the HTML5 Canvas 2D transform stack in [WasmPascal](https://wasmpascal.com/).

Demonstrates:
- Drawing complex shapes in local coordinate spaces.
- Composing transformations with `save`, `restore`, `translate`, `rotate`, and `scale`.
- Simultaneous animations: a rotating central gear, orbiting secondary shapes, and pulsating wave rows.
