# Multi-Dimensional Arrays

Demonstrates multi-dimensional array declarations and indexing in [WasmPascal](https://wasmpascal.com/).

Covers:
- Matrix declarations (`array[1..3, 1..4] of Integer`).
- Arrays indexed by custom enumerations.
- 3D cube arrays (`array[1..2, 1..2, 1..2]`).
- Nested loop traversals and linear memory layout verification.
