# Breakout Graphics

The HTML5 Canvas counterpart to the console Breakout game, compiled to WebAssembly via [WasmPascal](https://wasmpascal.com/).

Features:
- High-performance batched 2D canvas rendering at 60 fps.
- Web Audio sound effects synthesized live via browser audio contexts.
- Self-wiring keyboard event listeners attached to the DOM document.
- Smooth ball physics, paddle deflection dynamics, and brick destruction.

This example illustrates [WasmPascal](https://wasmpascal.com/)'s batched command wire format for rich web game development.
