# Math Built-ins

Comprehensive test and demonstration of built-in mathematical functions in [WasmPascal](https://wasmpascal.com/).

Exercises:
- Trigonometry: `Sin`, `Cos`, `ArcTan`
- Logarithmic and exponential: `Ln`, `Exp`
- Square root and powers: `Sqrt`, `Sqr`
- Rounding and absolute value: `Round`, `Trunc`, `Abs`

All functions map cleanly to standard WebAssembly math instructions and host imports.
