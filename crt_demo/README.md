# CRT Demo

Recreates the classic Borland Turbo Pascal 7 `Crt` unit environment in the browser using [WasmPascal](https://wasmpascal.com/).

Exercises:
- The 16 classic IBM PC / CGA text colors (`Black` through `White`).
- Screen clearing with `ClrScr`.
- Foreground and background color pairs via `TextColor` and `TextBackground`.
- Precise cursor placement using `GotoXY`.
