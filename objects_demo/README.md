# Turbo Pascal Objects

Demonstrates classic Borland Turbo Pascal 7 `object` value types in [WasmPascal](https://wasmpascal.com/).

Highlights:
- Object constructors and member methods.
- Virtual method tables (VMT) and dynamic dispatch.
- Single inheritance and calling base implementations with `inherited`.
- Stack value semantics as well as heap allocation with `New(p, Init(...))`.
