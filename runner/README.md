# Endless Runner

An endless runner platformer game inspired by Skoll, compiled to WebAssembly via [WasmPascal](https://wasmpascal.com/).

Features:
- Procedurally generated sliding platform slabs with gaps, crates, spikes, and collectible runes.
- Smooth jump physics with variable jump heights.
- Multi-layer parallax background hills and day-to-night ambient transitions.
- Web Audio synthesizer sound effects with zero external media files.
- Keyboard (Space/Up) and touch/tap controls.
